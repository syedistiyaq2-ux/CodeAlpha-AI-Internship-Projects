# FAQ Chatbot

## About the Project

This project is a simple FAQ chatbot made using Python.

The chatbot takes a question from the user and finds the most similar question from a list of frequently asked questions. It then displays the related answer.

## What I Did

* Created a simple chatbot interface using Tkinter
* Added frequently asked questions and answers
* Used TF-IDF to process the questions
* Used cosine similarity to find the closest question
* Added a basic response when no suitable answer is found

## Technologies Used

* Python
* Tkinter
* Scikit-learn

## How to Run

Install the required library:

```text
pip install -r requirements.txt
```

Then run:

```text
python faq_chatbot.py
```
