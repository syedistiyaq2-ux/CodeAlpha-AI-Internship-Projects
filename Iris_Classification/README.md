# Iris Flower Classification

## About the Project

I worked on this project to understand how machine learning can be used to identify different types of Iris flowers.

I used the Iris dataset and trained a Decision Tree model to predict the flower species.

## What I Did

- Loaded the Iris dataset
- Divided the data into training and testing parts
- Trained the Decision Tree model
- Tested the model with new data
- Checked the accuracy
- Created a confusion matrix to see the results

## Tools I Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Result

The model gave 100% accuracy on the test data used in this project.
