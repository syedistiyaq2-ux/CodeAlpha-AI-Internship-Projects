# Language Translation Tool

## About the Project

I created this project to understand how a simple language translation tool works using Python.

The application allows the user to enter text, select a source language and a target language, and get the translated text.

## What I Did

- Created a simple user interface using Tkinter
- Added source and target language selection
- Connected the application to a translation API
- Displayed the translated text
- Added basic error handling

## Technologies Used

- Python
- Tkinter
- Requests

## How to Run

Install the required library:

pip install -r requirements.txt

Then run:

python translation_tool.py

## Result

The application successfully translates entered text into the selected target language.s
