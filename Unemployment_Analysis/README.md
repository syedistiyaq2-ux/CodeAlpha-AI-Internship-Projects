# Unemployment Analysis with Python

## About the Project

I worked on this project to understand how unemployment rates changed in India over different years.

I used Python to organize the data and create a graph to make the changes easier to understand.

## What I Did

- Created the unemployment data
- Used Pandas to work with the data
- Checked some basic statistics
- Created a line graph
- Observed the changes in unemployment rates

## Tools I Used

- Python
- Pandas
- Matplotlib
- Seaborn

## Result

The project shows the unemployment rate for different years through a line graph.
